Why Do We Need Loops? 🔁

What: Loops let you repeat code automatically — without copy-pasting.
When: Any time you process a list of items, repeat until something happens, or build a sequence.
Why: DRY principle — Don't Repeat Yourself. Loops are one of the most powerful tools in programming.
# why_loops.py
# ❌ Without loops — tedious and fragile
print("Student 1: Ali")
print("Student 2: Siti")
print("Student 3: Ravi")
# What if you have 1000 students?!

# ✅ With a loop — handles any number
students = ["Ali", "Siti", "Ravi"]
for i, s in enumerate(students, 1):
    print(f"Student {i}: {s}")

# Loops in real life:
# - Send email to all subscribers
# - Check each order in a database
# - Process every pixel in an image
# - Keep asking until valid input
# - Add up all items in a cart

for loop

  • Iterate over list, string, range
  • Knows exactly how many items
  • Stops automatically when done
  • Best for: collections, sequences

while loop

  • Runs while condition is True
  • You control when it stops
  • Risk: infinite loop if not careful
  • Best for: menus, unknown count

Loop control

  • break — exit loop immediately
  • continue — skip to next item
  • else — run after loop ends
  • range() — generate numbers

for Loop — Iterate Over Anything 🔄

How: for [variable] in [sequence]: — Python assigns each item to the variable one at a time.
range(start, stop, step) generates numbers. range(5) = 0,1,2,3,4. range(1,6) = 1,2,3,4,5.
# for_loop.py
# Loop over a list
fruits = ["mango", "durian", "rambutan"]
for fruit in fruits:
    print(f"I love {fruit}!")

# range() — generate numbers
for i in range(1, 6):      # 1 2 3 4 5
    print(i, end=" ")

# range with step
for n in range(0, 20, 5):   # 0 5 10 15
    print(n)

# enumerate — index + value
for i, fruit in enumerate(fruits, 1):
    print(f"{i}. {fruit}")

# Loop over string
for char in "Python":
    print(char, end="-")   # P-y-t-h-o-n-

# break and continue
for n in range(10):
    if n == 5: break        # stop at 5
    if n % 2 == 0: continue # skip evens
    print(n)                  # 1 3

Useful loop patterns

  • Sum: total += item inside loop
  • Count: count += 1 inside loop
  • Find max: if item > max_val: max_val = item
  • Build string: result += word
  • Filter: if condition: new_list.append(item)

List comprehension — one-liner

  • [x*2 for x in range(5)]
  • [x for x in nums if x > 0]
  • [x**2 for x in range(1,6)]
  • Shorter and faster than a for loop + append

while Loop — Repeat Until Done ⏰

When: Use while when you don't know in advance how many times to repeat — like asking for input until it's valid, or running a menu until the user quits.
Warning: Always ensure the condition eventually becomes False or use break.
# while_loop.py
# Keep asking until valid input
while True:
    age_str = input("Enter age (1-120): ")
    if age_str.isdigit():
        age = int(age_str)
        if 1 <= age <= 120: break
    print("Invalid! Try again.")

# Number guessing game
secret   = 42
attempts = 0
while True:
    guess    = int(input("Guess: "))
    attempts += 1
    if   guess < secret: print("Too low 📉")
    elif guess > secret: print("Too high 📈")
    else:
        print(f"✅ Got it in {attempts} tries!")
        break

# Menu loop
while True:
    print("1) Add  2) View  3) Quit")
    choice = input("Choice: ")
    if choice == "3": break

for vs while

  • for → you know the count (range, list)
  • while → you don't know when it ends
  • Menu loops → always while True + break
  • Input validation → always while True + break
  • Countdown → either works, for is cleaner
⚠️ Infinite loop: if your condition never becomes False and you have no break, the program runs forever. Add a max_attempts counter as a safety net.

Lists — Ordered Collections 📋

What: A list holds multiple values in order, in a single variable.
When: Shopping cart, student names, scores, task list — any collection of similar items.
Why: Without lists, you'd need a separate variable for every item.
# lists.py
# Create a list
scores = [85, 92, 67, 78, 90]
names  = ["Ali", "Siti", "Ravi"]
mixed  = [1, "hello", True, 3.14]

# Access by index (starts at 0)
print(scores[0])   # 85 — first
print(scores[-1])  # 90 — last
print(scores[1:3]) # [92, 67] — slice

# Modify
scores.append(95)  # add to end
scores.insert(0, 70) # insert at index
scores.remove(67)  # remove first match
scores.pop()       # remove last, return it

# Useful functions
print(len(scores))  # count items
print(sum(scores))  # total
print(max(scores))  # highest
print(min(scores))  # lowest
scores.sort()       # sort in place
sorted(scores)      # returns new sorted list

List comprehension

  • Build a new list in one line:
  • [x for x in nums]
  • [x*2 for x in range(5)]
  • [x for x in nums if x > 50]
  • [s.upper() for s in names]
  • Faster and more Pythonic than a for loop!

Slicing syntax: list[start:stop:step]

  • scores[1:3] → items at index 1,2
  • scores[:3] → first 3
  • scores[-2:] → last 2
  • scores[::-1] → reversed copy
  • scores[::2] → every other

Dictionaries — Key:Value Storage 📖

What: A dict stores data as key:value pairs — like a real dictionary where you look up a word and find its meaning.
When: Storing a student record, user profile, product catalogue, config settings.
Why: Instant lookup by name — much faster than searching a list.
# dicts.py
# Create a dictionary
student = {
    "name":   "Ali",
    "age":    22,
    "score":  87.5,
    "passed": True
}

# Read values
print(student["name"])            # Ali
print(student.get("grade", "N/A")) # N/A (safe!)

# Update & add
student["score"] = 92.0   # update
student["grade"] = "A"    # add new key

# Delete
del student["passed"]
removed = student.pop("age")

# Loop over dict
for key, val in student.items():
    print(f"{key}: {val}")

# Dict comprehension
doubled = {k: v*2 for k,v in {"a":1,"b":2}.items()}

dict vs list

  • list → access by position [0]
  • dict → access by name ["name"]
  • List: ordered, sequential data
  • Dict: labelled data (records, profiles)
  • Dict lookup is O(1) — instant, no matter the size!
⚠️ d["missing_key"] → KeyError crashes. Use d.get("key", "default") for safe access.

Nested dicts — real-world data

  • students["ali"]["score"]
  • Every JSON API returns nested dicts
  • Master nested dicts → master web APIs

Nested Dicts — Real-World Data 🗂️

What: A dict inside a dict. This is exactly how JSON data from APIs looks.
When: Every web API returns nested dicts. User profiles, product catalogues, database records.
Why: Understanding nested dicts = understanding every dataset on the internet.
# nested_json.py
# Nested dict — dict of dicts
students = {
    "ali":  {"score": 87, "grade": "B", "city": "KL"},
    "siti": {"score": 95, "grade": "A", "city": "JB"},
    "ravi": {"score": 72, "grade": "C", "city": "PG"},
}

# Access nested values
print(students["siti"]["score"])    # 95
print(students["ali"].get("grade")) # B

# Loop over nested dict
for name, info in students.items():
    print(f"{name}: {info['score']} ({info['grade']})")

# Save and load as JSON
import json
with open("students.json", "w") as f:
    json.dump(students, f, indent=2)

with open("students.json") as f:
    loaded = json.load(f)
print(loaded["ali"]["city"])  # KL

JSON — the language of the internet

  • json.dump(data, f) — Python dict → file
  • json.load(f) — file → Python dict
  • json.dumps(data) — dict → string
  • json.loads(text) — string → dict
  • indent=2 makes it human-readable

Dict comprehension

  • Extract one field: {k:v["score"] for k,v in students.items()}
  • Filter high scores: {k:v for k,v in scores.items() if v >= 80}
  • Very useful for transforming API responses

👨‍🏫 Teacher Demo: Contact Book with Save/Load

Lists + Dicts + JSON + while loop — all in one program

# contact_book.py
import json, os

FILE = "contacts.json"
contacts = json.load(open(FILE)) if os.path.exists(FILE) else {}

def save():
    with open(FILE, "w") as f: json.dump(contacts, f, indent=2)

while True:
    print("\n1)Add 2)Search 3)List 4)Delete 5)Quit")
    c = input("Choice: ")
    if c == "1":
        n = input("Name: ")
        contacts[n] = {"phone": input("Phone: "), "email": input("Email: ")}
        save()
        print(f"✅ {n} saved!")
    elif c == "2":
        n = input("Search name: ")
        print(contacts.get(n, "Not found"))
    elif c == "3":
        for n, info in contacts.items(): print(f"{n}: {info}")
    elif c == "4":
        n = input("Delete: "); contacts.pop(n, None); save()
    elif c == "5": break
