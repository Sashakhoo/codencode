Why Do We Need Conditions? 🤔

What: Conditions let your program make decisions — different paths for different situations.
When: Any time the outcome depends on a value. Login checks, age verification, score grading, price calculations.
Why: Without conditions, every program runs the same steps every time — no intelligence.
# without_vs_with.py
# ❌ Without conditions — no intelligence
print("Access granted")  # always! even wrong password

# ✅ With conditions — smart decisions
password = input("Password: ")
if password == "secret123":
    print("✅ Access granted!")
else:
    print("❌ Wrong password!")

# Real-world examples of conditions:
# - Bank: enough balance? if balance >= amount
# - Age gate: can vote? if age >= 18
# - Grade: A, B, C, D, F based on score
# - Login: username AND password correct?
# - Discount: member? then 20% off

🏦 Banking

  • Enough balance? → allow withdrawal
  • Is member? → apply discount
  • Suspicious login? → send OTP

🎮 Games

  • Player health > 0? → keep playing
  • Score > 1000? → next level
  • Bonus collected? → add power

🌐 Web apps

  • Logged in? → show dashboard
  • Admin? → show admin panel
  • Form valid? → save to database

if / elif / else — The Decision Tree 🌳

How it works: Python checks each condition top to bottom and runs the FIRST block that is True. Once one block runs, the rest are skipped.
# conditions.py
# Basic if / else
age = int(input("Age: "))
if age >= 18:
    print("You can vote! 🗳️")
else:
    print("Not yet — check back later")

# Multiple branches with elif
score = int(input("Score: "))
if   score >= 90: print("A — Excellent!")
elif score >= 80: print("B — Good job!")
elif score >= 70: print("C — Pass")
elif score >= 60: print("D — Borderline")
else:              print("F — Retake")

# Ternary — one-liner condition
status = "adult" if age >= 18 else "minor"
print(f"Status: {status}")

Comparison operators

  • == equal to    != not equal
  • > greater    < less
  • >= greater or equal   <= less or equal

Rules to remember

  • Colon : at the end of every if/elif/else
  • Indent 4 spaces inside each block
  • elif and else are optional
  • You can have as many elif as needed
  • Order matters — Python checks TOP to BOTTOM
⚠️ == is comparison. = is assignment. if x = 5: is a SyntaxError!

Logical Operators — and / or / not 🔧

What: Combine multiple conditions into one check.
When: Login needs username AND password correct. Discount applies if member OR spending > RM100.
# logical.py
# and — BOTH must be True
username = input("Username: ")
password = input("Password: ")
if username == "admin" and password == "secret":
    print("Welcome, admin!")

# or — EITHER can be True
is_member = True
spending  = 150
if is_member or spending > 100:
    print("10% discount applied!")

# not — flips True to False
is_banned = False
if not is_banned:
    print("You may enter.")

# Combine all three
age   = 20
score = 85
if age >= 18 and score >= 80 and not is_banned:
    print("Eligible for scholarship!")

Truth table summary

  • True and True → True
  • True and False → False
  • False or True → True
  • False or False → False
  • not True → False
  • not False → True

Real-world logic patterns

  • Login: username == X and password == Y
  • Discount: is_member or total > 100
  • Entry: age >= 18 and not is_banned
  • Holiday: day == "Sat" or day == "Sun"
💡 Short-circuit evaluation: Python stops checking as soon as the result is determined. False and [anything] → Python never checks [anything].

match — Pattern Matching (Python 3.10+) 🎯

What: Like a cleaner version of multiple elif checks. Perfect when comparing one variable against many fixed values.
When: Menu selections, command parsing, status codes, day names.
# match_stmt.py
# match — cleaner than many elif
day = input("Day: ").lower()

match day:
    case "monday":
        print("Start of the week!")
    case "friday":
        print("Almost weekend!")
    case "saturday" | "sunday":
        print("Weekend! 🎉")
    case _:
        print("A regular weekday")

# match with numbers
status = 404
match status:
    case 200: print("OK ✅")
    case 404: print("Not Found 🔍")
    case 500: print("Server Error 💥")
    case _:   print(f"Unknown: {status}")

Common bugs to avoid

  • Missing : after if/elif/else/case — SyntaxError!
  • Wrong indentation inside block — IndentationError
  • Using = instead of == — logic error
  • Checking string "True" instead of bool True
  • Condition order matters — put specific before general

Debugging conditions

  • Add print() before the if to see actual values
  • Print type(value) if comparison is behaving oddly
  • Use parentheses to clarify complex conditions
  • Test each condition separately first
💡 _ in match is the "catch-all" — like else. | means OR between cases.

👨‍🏫 Teacher Demo: Grade Classifier + Login System

Full program combining if/elif/else with logical operators

# grade_login.py
# ── Part 1: Grade Classifier ──────────────
score = float(input("Enter score (0-100): "))

if   0 <= score <= 100:
    if   score >= 90: grade,msg = "A","Excellent!"
    elif score >= 80: grade,msg = "B","Good job!"
    elif score >= 70: grade,msg = "C","Pass"
    elif score >= 60: grade,msg = "D","Borderline"
    else:              grade,msg = "F","Retake needed"
    print(f"Grade: {grade} — {msg}")
else:
    print("Score must be 0-100!")

# ── Part 2: Login System ──────────────────
USERS = {"admin": "secret", "ali": "pass123"}
u = input("Username: ")
p = input("Password: ")

if u in USERS and USERS[u] == p:
    print(f"Welcome, {u}! ✅")
elif u not in USERS:
    print("Username not found ❌")
else:
    print("Wrong password ❌")
