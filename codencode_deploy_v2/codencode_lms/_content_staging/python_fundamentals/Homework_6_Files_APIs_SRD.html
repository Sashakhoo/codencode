🌐 API & File Tasks
Task 1: Country Explorer
⭐ Easy

Use RestCountries API (no key needed). Ask for a country name. Display: official name, capital, population, area, currencies, languages, flag emoji. Handle not-found gracefully.

💡 URL: https://restcountries.com/v3.1/name/{country}
Task 2: Personal Diary App
⭐⭐ Medium

CLI diary saving to diary.json (list of dicts: date, title, content, mood). Features: write entry, read today, search by keyword, export to diary_export.txt. Handle all file errors with try/except.

Task 3: Crypto Price Tracker
⭐⭐ Medium

CoinGecko API (free): fetch BTC, ETH, DOGE prices in MYR and USD every 60 seconds. Save each fetch to prices.json with timestamp. Show price change since first fetch.

💡 Use time.sleep(60) in a while loop. Ctrl+C to stop gracefully.
Task 4: Your Project SRD
⭐⭐⭐ Required

Write a complete SRD for YOUR project idea as srd.md. Must include: (1) App name + 1-sentence description, (2) Problem statement, (3) Target user profile, (4) 3 MVP features only, (5) Tech stack with justification, (6) Data model, (7) 2 risks and mitigations, (8) Success metric.

✅ This is the most important task. Your project starts here.

  • SRD written in full sentences (not just bullet fragments)
