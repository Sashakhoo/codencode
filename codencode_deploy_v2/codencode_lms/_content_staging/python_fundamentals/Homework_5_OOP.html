Task 1: Contact Manager
⭐ Easy

Contact class: name, phone, email, category. Methods: display(), update(field, value), matches(query). ContactBook class: add, remove, search, list_by_category.

Task 2: Vehicle Fleet
⭐⭐ Medium

Base Vehicle(make, model, year, mileage). Subclasses: Car(doors=4), Truck(cargo_kg), ElectricCar(battery_kwh, range_km). All have drive(km). Truck reduces cargo when loaded. ElectricCar loses range.

💡 Override drive() in each subclass. Call super().drive(km) first.
Task 3: Library System
⭐⭐ Medium

@dataclass Book(title, author, isbn, year, available=True). Library: add_book, checkout(isbn), return_book(isbn), search(query), overdue_books() (checked out 14+ days). Track checkout_date.

Task 4: RPG Character System
⭐⭐⭐ Hard

Base Character(name, hp, attack, defence). Subclasses: Warrior(shield_bonus), Mage(mana, spells), Rogue(stealth). Methods: attack_target(other), defend(), is_alive(). Simulate 3-round battle between 2 characters.

✅ Bonus: Add __repr__ to all classes and a Battle class that logs each round
