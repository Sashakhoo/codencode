What is a Function? Why Use One? 🔧

What: A function is a named, reusable block of code. Define it once, call it anywhere.
Why: Without functions, you copy-paste the same code everywhere. Change it in one place → it changes everywhere.
# why_functions.py
# ❌ Without functions — repeated code
print("Hello, Ali! Welcome.")
print("Hello, Siti! Welcome.")
print("Hello, Ravi! Welcome.")
# Change the message? Edit 3 lines.

# ✅ With a function — define once, call anywhere
def greet(name):
    print(f"Hello, {name}! Welcome.")

greet("Ali")
greet("Siti")
greet("Ravi")
# Change message? Edit 1 line. Done.

4 reasons to use functions

  • 1. DRY — Don't Repeat Yourself
  • 2. Readable — code reads like English: greet(), calculate(), validate()
  • 3. Testable — test one function at a time
  • 4. Maintainable — fix a bug in one place, fixed everywhere

Analogy: a blender 🍹

  • Parameters = ingredients you put in
  • Calling the function = pressing the button
  • Return value = the smoothie you get out
  • Without return, the blender makes nothing you can use

def & return — Create and Use Functions 🏗️

def defines (creates) a function blueprint. return sends a value back to the caller. Without return, a function returns None. Always define BEFORE calling!
# functions.py
# Basic function — no return
def greet(name):
    print(f"Hello, {name}!")

greet("Ali")   # Hello, Ali!

# Function with return value
def add(a, b):
    return a + b

result = add(3, 5)   # result = 8
print(result)         # 8
print(add(10,20))    # 30 — use directly

# Multiple return values
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([3,1,9,4])
print(lo, hi)         # 1  9

# Early return for validation
def divide(a, b):
    if b == 0: return None  # guard clause
    return a / b

print vs return

  • print() — shows on screen, value is gone
  • return — sends value back, can store + reuse
  • Use return when the caller needs the result
  • A function that only prints is a dead end

Default parameters

  • def greet(name, greeting="Hello"):
  • Default = fallback if not provided
  • Defaults go LAST in parameter list
  • Call: greet("Ali") or greet("Ali", "Hi")
⚠️ Required params FIRST, defaults LAST: def fn(a, b=5) ✅ def fn(a=5, b) ❌

Scope — Where Variables Live 🌍

Local variable — created inside a function, dies when function ends.
Global variable — created outside, readable everywhere.
Best practice: pass data IN as parameters, send data OUT with return. Avoid global.
# scope.py
score = 100   # GLOBAL variable

def show_score():
    print(score)    # ✅ can READ global

def set_score():
    score = 200    # creates LOCAL copy!
    print(score)    # 200 (local)

show_score()    # 100
set_score()     # 200
print(score)     # 100 — global unchanged!

# ❌ Avoid: global keyword
def add_score(pts):
    global score
    score += pts   # modifies global — risky!

# ✅ Better: pass in, return out
def add_score(current, pts):
    return current + pts

score = add_score(score, 50)  # 150 ✅

Scope analogy

  • Function = a locked room
  • Variables inside can't be seen outside
  • Variables outside can be READ inside
  • To change outside data: use parameters + return

*args & **kwargs

  • *args — any number of positional args → tuple
  • **kwargs — any number of keyword args → dict
  • def total(*numbers): return sum(numbers)
  • total(1,2,3) or total(1,2,3,4,5) — both work!
💡 The * and ** are the magic — the names args and kwargs are just convention. You can use *nums and **opts.

Modules & import — Python's Toolboxes 📦

What: A module is a file of Python code you can import and use. Python has hundreds of built-in modules — math, random, datetime, json, os.
When: Anytime you need a function that's already been written — don't reinvent the wheel!
# modules.py
import random
import math
from datetime import date, datetime

# random — generate random values
n    = random.randint(1, 100)    # random int
pick = random.choice(["rock","paper","scissors"])
items = [1,2,3,4]
random.shuffle(items)            # shuffle in place

# math — mathematical functions
print(math.sqrt(16))    # 4.0
print(math.floor(3.9))  # 3
print(math.ceil(3.1))   # 4
print(math.pi)           # 3.14159...
print(math.log(100, 10)) # 2.0

# datetime — dates and times
today = date.today()
print(today)               # 2026-06-30
now   = datetime.now()
print(now.strftime("%d %b %Y %H:%M"))

# Your own module: save as utils.py
# then in main.py:
# from utils import greet, add

3 types of modules

  • Built-in — random, math, datetime, json, os (free, already installed)
  • Third-party — pip install requests, flask...
  • Your own — save as helper.py, then from helper import ...

Two import styles

  • import math → math.sqrt(16)
  • from math import sqrt → sqrt(16)
  • from math import sqrt, pi, floor
  • import math as m → m.sqrt(16)

Lambda — one-line functions

  • square = lambda x: x**2
  • add = lambda a,b: a+b
  • Used with sorted(): sorted(students, key=lambda s: s["score"])
  • Perfect for short, throwaway functions

👨‍🏫 Teacher Demo: Utility Library + Grade System

Build a reusable set of functions, then use them together

# utils.py + main.py
# ── utils.py ──────────────────────────────
def clamp(value, lo=0, hi=100):
    """Keep value within bounds."""
    return max(lo, min(hi, value))

def grade(score):
    """Return letter grade for score."""
    score = clamp(score)
    if   score>=90: return "A"
    elif score>=80: return "B"
    elif score>=70: return "C"
    elif score>=60: return "D"
    else:            return "F"

def stats(*scores):
    """Return dict of stats for any number of scores."""
    return {"count":len(scores),"avg":sum(scores)/len(scores),
            "min":min(scores),"max":max(scores)}

# ── main.py ───────────────────────────────
from utils import grade, stats

scores = [85, 92, 67, 78]
for s in scores:
    print(f"{s} → {grade(s)}")
print(stats(*scores))
