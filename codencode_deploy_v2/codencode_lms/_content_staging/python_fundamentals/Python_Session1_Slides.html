What is Python? 🐍

Python is a programming language that reads like English. No curly braces, no semicolons. Created in 1991 by Guido van Rossum — named after Monty Python, not the snake!

🌍 Most Popular

  • #1 language worldwide (TIOBE 2024)
  • Used by Google, NASA, Netflix, Instagram
  • Massive community = help is everywhere

⚡ What can you build?

  • Web apps (Django, Flask)
  • AI & machine learning
  • Data analysis & visualisation
  • Automation scripts
  • APIs & backends

📝 Why is it beginner-friendly?

  • Reads like English sentences
  • No need to declare types
  • Errors are descriptive
  • One right way to do most things
  • Huge library of ready-made tools
💡 Fun fact: Python is #1 in AI/ML, #1 for beginners, and top 3 for web development. One language, endless possibilities.

Variables — Labelled Boxes 📦

What: A variable is a named container that stores a value in memory.
When: Any time you need to remember information — a name, a score, a price.
Why: Without variables, you'd have to write the same value everywhere.
# variables.py
# Assign a value to a name
name       = "Aisha"   # str — text
age        = 16        # int — whole number
height     = 1.62      # float — decimal
is_student = True      # bool — True or False

# Use them in output
print(f"Hello, {name}! Age: {age}")

# Update a variable
age = 17           # overwrite
print(age)          # 17

# Naming rules
my_score  = 95     # ✅ underscore OK
score2    = 90     # ✅ numbers OK (not first)
# 2score = 90         ❌ cannot start with number
# my score = 90      ❌ no spaces

4 Data Types

  • str — "Hello" · text in quotes
  • int — 16, -3, 0 · whole numbers
  • float — 1.62, 3.14 · decimals
  • bool — True or False only

Good naming habits

  • Use lowercase with underscores: first_name
  • Be descriptive: user_score not s
  • No Python keywords: not, if, for, while...
  • type() shows you what type a variable is: type(age)
🐧 codencode AcademySession 1 · print() & input()

print() & input() — Talk to Python 🗣️

print() — display output on screen. input() — receive text from user.
Critical rule: input() ALWAYS returns a string — even if the user types a number!
# interact.py
# print() — show anything
print("Hello World!")
print(42)
print(True)
name = "Aisha"
print(f"Hello, {name}!")    # f-string
print(f"Age: {age}, Height: {height:.2f}")

# input() — get from user
age_str = input("Your age: ")
print(type(age_str))    # <class 'str'>

# MUST convert before math
age = int(age_str)         # "16" → 16
print(f"Next year: {age+1}")

# Or combine in one line
weight = float(input("Weight kg: "))
city   = input("Your city: ")   # stays str ✅

f-string formatting

  • f"Hello, {name}" — insert variable
  • f"{price:.2f}" — 2 decimal places
  • f"{score:.1f}" — 1 decimal place
  • f"{num:,}" — add commas: 1,000
  • f"{num:05d}" — pad with zeros: 00042
⚠️ input() ALWAYS returns a string! "16" + 1 causes TypeError. Always convert: int(), float()
💡 String multiplication: print("=" * 30) prints 30 equal signs — great for separators!
🐧 codencode AcademySession 1 · Type Casting

Type Casting & type() 🔄

What: Converting a value from one data type to another.
When: Whenever you get input from users (always strings) and need to do math.
How: Wrap the value in int(), float(), str(), or bool().
# casting.py
# Check the type of anything
print(type("hello"))     # <class 'str'>
print(type(16))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type(True))        # <class 'bool'>

# int() — string/float → integer
int("95")      # → 95
int(3.9)       # → 3  (truncates!)

# float() — string/int → decimal
float("1.72")  # → 1.72
float(5)       # → 5.0

# str() — anything → text
str(100)       # → "100"
str(True)      # → "True"

# bool() — falsy values → False
bool(0)        # → False
bool("")       # → False (empty string)
bool(42)       # → True
bool("hello")  # → True

Common casting mistakes

  • int("3.14") → ❌ ValueError (use float first!
  • float("hello") → ❌ ValueError
  • int(True) → 1, int(False) → 0
  • When unsure: wrap in try/except

Arithmetic operators

  • + addition · - subtraction
  • * multiply · / divide (float)
  • // floor divide · % remainder
  • ** power: 2**10 = 1024
  • round(3.14159, 2) → 3.14

🐛 Debugging — Reading Error Messages

Errors are not failures — they are clues. Every developer sees errors every single day. The skill is learning to read them, not fear them. Python's errors are very helpful — they tell you exactly what went wrong and where.
SyntaxError — Python can't read your code
print("Hello" ← SyntaxError: '(' was never closed
Fix: Check all brackets and quotes are closed
TypeError — Wrong type for an operation
age = "16"; print(age + 1) ← TypeError
Fix: Convert with int(age) first
NameError — Variable not defined
print(nme) ← NameError: 'nme' is not defined
Fix: Check spelling — it's probably name
ValueError — Right type, wrong value
int("hello") ← ValueError: invalid literal
Fix: Only cast strings that contain numbers

How to debug like a pro

  • ① Read the error TYPE (first word)
  • ② Find the line number in the traceback
  • ③ Look at that line + the one above
  • ④ Check spelling — typos = #1 cause
  • ⑤ Google: copy error message → paste
  • ⑥ Ask AI: paste code + error message
💡 AI debugging prompt: "My Python code gives this error: [paste error]. Here is my code: [paste code]. What is wrong and how do I fix it?"
✅ Once you can read error messages, you can fix 80% of bugs yourself in under 2 minutes.

🐙 Git & GitHub — Save Your Code Forever

Git = version control. Tracks every change you make to your code.
GitHub = cloud storage for Git. Like Google Drive for code — accessible anywhere, shareable with anyone.
Why it matters: Every developer uses Git. It's a non-negotiable skill.

Without Git 😰

  • project.py
  • project_v2.py
  • project_FINAL.py
  • project_FINAL2.py
  • project_FINAL_real.py

With Git 😎

  • One file only
  • Every version saved
  • Go back anytime
  • Share with the world
  • Your coding portfolio!

The 4 Git commands you need

  • git init — start tracking a folder
  • git add . — stage all changed files
  • git commit -m "message" — save snapshot
  • git push — upload to GitHub
# terminal
# Step 1: Initialise git in your project folder
git init

# Step 2: Stage all files
git add .

# Step 3: Save a snapshot
git commit -m "My first Python program 🐍"

# Step 4: Connect to GitHub and push
git remote add origin https://github.com/yourname/repo.git
git push -u origin main

# Future commits are just:
git add .
git commit -m "Add BMI calculator"
git push

# Check status anytime
git status
git log --oneline  # see all commits

🤖 Vibe Coding — Your AI Superpower!

Vibe coding = describing what you want in plain English → AI writes the code → you read, test, and improve it. Used by 75%+ of professional developers every single day.

Tools for vibe coding

  • Claude (claude.ai) — best for explanations
  • ChatGPT (chatgpt.com) — general purpose
  • GitHub Copilot — in-editor suggestions
  • Cursor (cursor.sh) — AI-powered code editor
⚠️ Never copy AI code blindly! AI makes mistakes. You need to understand the code to catch bugs — that's exactly why we teach Python properly.
💡 AI is a tool, not a replacement. The developers earning the most are those who know how to direct AI effectively.
Your first vibe coding prompt — try it now:
"Write a Python program that:
- Asks the user for their name and age
- Calculates what year they were born  
- Prints a nicely formatted message
- Add a comment on every line explaining it"

After getting AI code — do this:

  • ① Read every line — do you understand it?
  • ② Run it — does it work correctly?
  • ③ Break it — change a value, see what happens
  • ④ Improve — add one more feature yourself
  • ⑤ Ask AI to explain any line you don't understand
